# Release Notes

## Latest
- Support user group mentions: `@team ++` awards 1 paw to each group member
  who is in the channel (requires the `usergroups:read` scope).
- Count `++` only when adjacent to a mention (space optional).
- Support awarding from edited messages.
- Admin-only :point_down: on bot award messages to undo 1 point with a thread reply.
